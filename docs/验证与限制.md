# 验证记录与限制

记录日期：2026-09-18。验证对象为一台 EMW3080B / MX1290 斐讯 M1，不能外推到所有批次。

## 已有实机证据

- SWD 路径完成设备自身 Flash 备份；应用区写入后曾独立读回校验。
- 温度、湿度、甲醛与 PM2.5 曾在 HA 收到实际数据。
- 用户已确认亮度控制能改变实物显示。
- 手机曾成功访问 `192.168.4.1`，当前用户确认完成网页配网并接入 HA。
- 热点不可见后，一次受控复位恢复了实际无线广播；独立扫描曾持续观察约 150 秒，不能代替长期稳定性测试。

以上实机结果来自本项目开发过程和用户反馈，不是在公开发布时重新擦写设备取得。原始备份、抓包和私人网络日志不进入公开仓库。

## 主机回归

`python scripts/run_tests.py` 覆盖：传感器已知帧解析；扫描去重、最强 64 个 SSID、RSSI 排序、完成序号、重复请求抑制、超时重试、空结果、长 JSON 和字符转义；OTA 打包输入校验与发布工具输出。测试不连接硬件。

页面移动端模拟和本地构建在开发过程中做过验证；当前公开仓库不把私有环境截图当作可复现测试，也不以编译成功声称 RF 或 OTA 验收成功。

## 仍然开放的问题

1. **SoftAP 偶发不可见。** 内部标志显示启动不代表真实 beacon 广播；复位恢复只是现象，不是根因修复。
2. **Wi-Fi 图标。** 主控网络状态协议未完成可靠验收。联网正常时也可能不亮。
3. **完整无线 OTA。** 当前版从下载、暂存、校验到启动新应用并保留配置的全链路须补测；断电、失败恢复和降级不能对外承诺。
4. **首刷交付。** 原版斐讯固件 → TTL 首刷 → 手机配网 → HA 的通用新手包尚未验收。开发设备的 SWD 成功不等于此流程已完成。
5. **配置失败反馈。** 保存成功之后才连接 Wi-Fi，暂无在原门户完整展示认证/DHCP/MQTT 失败并自动回退的机制；隐藏 SSID 和凭据清除操作仍需改进。
6. **安全加固。** 本地管理无认证、HTTP 明文、MQTT 当前未启用 TLS、OTA 无发布者签名；只能在可信隔离网络使用。
7. **数据新鲜度。** 当前可重复发送最后样本；MQTT 在线不等于传感器一直有新数据，须结合 UART 计数判断。
8. **配置持久化。** Wi-Fi/MQTT 有参数存储，亮度没有持久化；新配置结构和旧版降级需要迁移测试。
9. **兼容矩阵。** WPA3-only、企业认证、所有 AP/手机系统、长时间运行及多设备并发尚无全面实测。

## 下一次稳定版的验收条件

- 原版机器首刷、救援与完整备份恢复各走通一遍。
- 多种手机热点配网页验证，扫描前后持续检查真实广播，不只看内部状态。
- Wi-Fi 错密码、AP 失联、DHCP 超时、MQTT 拒绝等故障有清晰可恢复路径。
- 从旧公共版本执行真实 OTA，逐项核对 Wi-Fi/MQTT 保留、新版本上报和传感器更新。
- 故障注入及断电测试在可救援设备上进行，明确失败边界。
- 完成依赖再分发许可确认后，再评估是否发布二进制安装包。
