# 配网与日常使用

适用于已经安装本项目兼容内核及应用的设备；不是原厂 TTL 首刷教程。

## 1. 准备自己的 MQTT 服务

先在 Home Assistant 配置好 MQTT 集成及其使用的 Broker。记录主机名或 IPv4、端口、用户名和密码。默认端口填 1883，但应以你的服务实际配置为准；仅把端口改成 8883 不会启用 TLS。

固件没有默认 MQTT 账号，也不需要开发者账号。MQTT 可以和 HA 同机，也可以独立部署。确认设备网段能访问 Broker；跨网段需要正确的路由和防火墙规则，不能仅凭 IP 相近推断互通。

## 2. 连接配网热点

没有有效 MQTT 配置时，固件进入 `M1-Setup-xxxxxx` 首配热点。手机连上后提示“无互联网”是正常的：这是本地配置网络，不是上网路由器。

优先使用系统弹出的登录页；未弹出则打开 **http://192.168.4.1/**，不要使用 HTTPS。若手机通过移动数据或 VPN 绕开本地网络，可临时关闭移动数据、VPN及自动切换网络，并选择继续连接该热点。配网完成后恢复手机原设置。

若热点根本不可见，这是另一个问题，不应误判为密码错误。开发版本有过热点不可见的已知故障；确认没有升级/写入正在进行后，可尝试一次正常断电重启。重启恢复不代表根因已修复；持续失败请提交脱敏日志，不要反复擦除参数。

## 3. 扫描并保存

1. 在 SSID 选择区域后点击扫描，等待“扫描中”结束。
2. 从信号强到弱的列表选择 2.4 GHz 网络。同名网络合并，仅显示信号最强的条目；隐藏网络不显示，最多保留 64 个不同 SSID。
3. 填 Wi-Fi 密码及 MQTT 主机、端口和认证信息；开放网络可空密码。当前没有验证 WPA3-only、企业认证或所有 Mesh/路由器组合。
4. 点击“保存并应用”。页面会先提示保存，再提示重启；失败时显示错误。不要在保存过程中拔电。
5. 手机手动切回家庭网络。设备不能替手机切换 Wi-Fi，也不能让旧的 `192.168.4.1` 页面在换网后自动获得新 IP。

当前先持久化、后重启连接。因此“已保存”不代表 Wi-Fi 密码正确，页面尚不能完整区分后续认证失败、DHCP 失败和 MQTT 失败，也不支持失败自动回退候选配置。

## 4. 找到设备和 HA 实体

从路由器 DHCP 列表查设备地址；也可从 MQTT 的 `m1/<设备ID>/state` 读取 `wifi_ip`。浏览器访问 `http://设备IP/` 查看版本、SSID、IP 和 MQTT 设置状态。

在 HA 的 MQTT 集成中查找“斐讯 M1”，通常会有温度、湿度、甲醛、PM2.5 和亮度 5 个实体。传感器实体在收到有效串口样本前不会拥有有效读数。

注意：管理页的“MQTT 已配置”只说明参数存在；Broker 实际连接是否成功应检查 MQTT 状态消息、Broker 日志和 HA 可用性。

## 5. 修改 MQTT 与亮度

同一管理页面可修改 MQTT 主机与端口。只改 MQTT 时将 Wi-Fi 密码留空，保留原 Wi-Fi；原密码不会显示在页面。当前 MQTT 凭据更新按一组处理：修改用户名或密码时应把两项都填完整，不能把空密码理解为“总是保留旧密码”。两项均留空且已完成配网时保留原凭据，清除原认证配置的 UI 仍待补齐。

亮度范围 0～4，0 关闭显示、4 最亮。重启后会发送启动亮度值，亮度尚未持久化；HA 显示的是应用命令状态，不是主控反向读回值。Wi-Fi 图标尚未可靠实现，不要依此判断联网是否正常。

## 常见问题

| 表现 | 优先检查 |
| --- | --- |
| 扫描条目少 | 是否为 5 GHz / 隐藏网络、是否同名合并、扫描有无完成；不保证所有手机能看到的 AP 都能被模块扫描到 |
| `ERR_EMPTY_RESPONSE` | 先确认手机获得 `192.168.4.x`；再检查设备 HTTP 服务和 SDK 的 1024 字节请求头适配，不要直接归因于手机 |
| 有 IP 但 HA 不出现 | Broker 地址/认证、网段连通、MQTT 集成是否使用同一个 Broker |
| HA 反复可用/不可用 | Broker 重连/同 ID 冲突、RSSI、状态消息是否持续；不要仅隐藏离线状态来掩盖问题 |
| HA 有值但不更新 | 对比 `uart_rx_bytes`、`uart_frames`、`uart_samples` 是否增长；旧样本仍可能被继续上报 |
| 找不到更新按钮 | 基础固件只自动发现传感器/亮度；更新实体需按 OTA 指南单独发布配置 |

详细状态主题与诊断字段见 [OTA 指南](OTA指南.md) 和源码 `m1_ha_mqtt.c`。
